# 运行画面与 GIF

这些媒体于 2026-10-15 从独立的本地演示工作台截取，使用与项目相同的服务和前端代码。运行数据保存在隔离目录，真实 QQ、微信、模型服务和用户消息均未接入；账号、通知、连接状态和模型输出使用模拟数据。画面上方有持续的演示环境标记。

`walkthrough.gif` 来自实际浏览器操作录制，展示通知进入、模拟整理结果、来源核对、人工完成待办、群聊管理、数据库维护、运行日志和桌面 QQ 优先时的暂停提示。它展示界面与操作流程，不构成真实客户端同时在线或真实模型语义理解的验证。
